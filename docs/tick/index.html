FAQ

Questions, answered

Is there really a free trial?

Yes. Every plan starts with 14 days free and there's nothing to pay to begin — you only subscribe when you're ready.

How does billing work?

You're billed once a year, in USD, for each active member. When you choose a plan you'll get a clear invoice with simple payment instructions, and your plan switches on as soon as it's settled.

Can I control the screenshots?

Completely. Turn them off, change how often they're taken, or blur them so the content stays private while you still see that work is happening.

Is it only for remote teams?

No. Office, remote or hybrid — Fitma Tick works the same way wherever your people sit.

What about privacy?

Activity is just a percentage worked out from keyboard and mouse use. No keystrokes are recorded, and each company's data is walled off so no one else can ever see it.

Which computers does it run on?

The desktop app runs on Windows and macOS. Managers and members can also open the dashboard in any web browser.
